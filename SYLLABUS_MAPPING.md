# CSE1021 Syllabus Mapping

I used the project to practise the basic programming topics from the course.

- **Problem solving:** I broke the attendance and student-record problem into smaller tasks.
- **Python basics:** The program uses variables, input/output, conditions, loops and functions.
- **Data handling:** Dictionaries and lists are used to keep student and marks data.
- **File handling:** JSON is used to save the data so it is still available after the program is closed.
- **Testing:** A few simple `unittest` cases are included for the calculations.

These topics are used directly in the project rather than being added only for the documentation.
