# Project Statement

## Why I made this project

I wanted to make a small program that keeps basic student information, attendance and marks together. Doing this manually in separate places can make it difficult to find a complete record.

## What it does

The project is a Python console application. A user can add and manage students, enter attendance and marks, and see simple reports. The information is saved in a local JSON file.

## Main features

- Student record management
- Attendance tracking
- Attendance percentage
- Subject marks
- Average and grade calculation
- Student summary
- Basic input checking
- Local data storage

## Limitations

The program is intended for a small academic project. It does not currently include a graphical interface, user accounts or an online database.
